# FileDeck v0.1.2 构建19发布说明

日期：2026-11-10。适用 macOS 14+、Apple Silicon（ARM64）；Release 配置，开发预览版。发布标签为 [`v0.1.2-build19`](https://github.com/liuweqwojeo/FileDeck/releases/tag/v0.1.2-build19)，源码与安装包对应关系见同一 Release 的 `SOURCE-CODE.md` 和 `BUILD-MANIFEST.json`。

## 本版变化

- 修复列表右键重命名面板刚打开就自动关闭。名称字段仅在回车时提交，按钮继续显式提交；失焦不提交，取消保留原文件，重名失败保留输入供修改重试。默认只选主体名，改变扩展名仍有明确提示。
- 新增 OFD 文档只读预览，支持多页、缩放、适合窗口及失败重试；通过内置内核离线转换，原文件不变。修复 OFD 缺省透明度及系统字体回退，使中文票据文字可见。
- 预览/编辑工作层铺满整个窗口内容区，顶部集中返回、编辑、保存、更多和 macOS 系统全屏。已保存文档的保存按钮随修改状态启用，状态集中显示；退出工作层恢复原窗口模式。
- 完善 CSV 单元格查找与编辑目标、PDF 查找与独立提取、合并排序，以及图片比例调整、可视裁剪和适合窗口。保存期间继续输入时保留新草稿，并推进已经实际完成的写盘身份。
- 完善目录列排序、面包屑、已加载目录筛选说明、递归搜索键盘操作、创建并编辑、文件复制粘贴快捷键、拖放悬停辅助，以及批次部分失败结果展示。Markdown 链接提供显式复制地址；文本撤销/重做保留换行信息。
- 保留构建14的触控板父子目录导航、网格图标与原生文档缩放、非 Office 草稿恢复及文件批次撤销。构建15至18为此前本机迭代，本次将这些配套源码、内核补丁和回归测试一并公开。

## 下载、校验与升级

ZIP：`FileDeck-0.1.2-build19-macOS-arm64.zip`，792,591,109 字节，约792.59 MB（755.87 MiB）。

SHA-256：`0dd02dfe50b905246ad120d95c66ff53b3891a0bab1eb16ce5e686f08b033d7e`。

1. 从本次 Release 下载 ZIP 和 `SHA256SUMS.txt`，放在同一目录执行 `shasum -a 256 -c SHA256SUMS.txt`。
2. 保存文档并正常退出旧版，解压后将完整 `FileDeck.app` 替换到“应用程序”，不要混合新旧应用包内容。
3. 启动核对版本0.1.2、构建19。在文件列表右键重命名，确认面板保持打开、输入后可通过回车或按钮完成改名。

无需另装 Node、Python、Microsoft Office 或辅助功能权限。源码、依赖锁、构建脚本和许可证入口见同一 Release 的 `SOURCE-CODE.md`；从源码首次构建 OFD 支持时需按[构建说明](onlyoffice-build.md#已有工作区升级-ofd-预览)编译内核。
