# FileDeck 0.1.0 macOS ARM64 开发预览版

## 本次发布

提供可直接下载的完整 FileDeck 应用，适用于 macOS 14+ 和 Apple Silicon。Office 内核、Markdown 与代码编辑资源均随包提供。

此次只调整打包和资源存储方式：在 `Contents/Resources/editors/web-apps` 内，将大小、权限、SHA-256 及完整字节比较均一致的图片改为包内相对链接。3,422 个重复图片路径复用原内容，减少 271,986,558 字节（约 259.39 MiB）。所有语言、字典、模板、插件、编辑器和原生二进制均保留。

应用版本为 `0.1.0`，构建号 `1`，应用标识不变；已有工作区设置和用户文档不需要迁移。数据库、SQL、Redis、MQ 和对外 API 无变更。

下载 ZIP 从 1021.80 MiB 降到 769.48 MiB，减少 24.69%。对照包与发布包均使用相同的 ZIP 压缩级别。

## 验证依据

- 95 项构建工具测试通过，包括移动整个应用后的链接、内容一致性、摘要碰撞、范围限制和报告写入边界。
- 对照精简前的下载包，23,975 个普通文件和 67 个既有链接均无意外变化；只允许应用版本、主程序签名和资源签名清单变化。
- 精简后的完整应用严格验签、ARM64、动态库依赖及资源静态检查通过。
- 实际断网 Office 验收通过：DOCX、XLSX、PPTX 新建、中文输入、保存、关闭、重开和内容核对；同时覆盖工作台混合文档和保存/退出保护。
- 44 项真实原生宿主检查通过，覆盖目录树点击、右键新建、预览、保存、焦点与滚动恢复。
- 6 项真实新建格式检查通过，覆盖 DOCX、XLSX、PPTX、PDF、PNG、JPEG。

本机验证日志保存在 `build/releases/v0.1.0/`，不随公开源码提交。复杂 Office 文档排版、中文输入法组合输入，以及其他机器的系统兼容性仍以实际使用结果为准。

## 安装与升级

1. 从本仓库的 [Releases](https://github.com/chuxin953/FileDeck/releases/tag/v0.1.0) 下载 ZIP 与 `SHA256SUMS.txt`，核对 SHA-256。
2. 使用 macOS 内置归档工具解压，保留整个 `.app` 的内部结构和相对链接。
3. 正常退出旧版 FileDeck，保留旧应用副本，再将新版拖入“应用程序”。
4. 打开后检查欢迎页、添加或继续工作区、目录树和右键新建；使用副本文档验证需要的编辑功能。

本版本只有临时签名，未完成 Developer ID 签名与 Apple 公证，macOS 可能阻止首次打开。确认来源与校验值后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 操作。此限制在下载页及包内安装说明中均有标明。

## 回退

退出新版并换回安装前保留的旧应用副本。本次不迁移用户数据，不需要还原数据库或执行回滚脚本。从源码打包时，上一份本机应用由原打包流程保存在 `build/previous-apps/`。

## 重建与源码

按 [完整构建说明](../onlyoffice-build.md) 获取锁定源码并构建后，执行：

```bash
python3 scripts/onlyoffice/package_app.py --version 0.1.0 --build-number 1
```

打包默认执行无损图片去重，在签名前操作暂存副本。`build/filedeck-resource-optimization.json` 记录每个别名、相对目标及摘要。遇到资源或验签失败时，不替换已存在的应用入口。

发行包的 `SOURCE-CODE.md` 指向本版本源码、集成补丁、构建脚本及上游固定提交；`licenses/` 附带 ONLYOFFICE 等上游许可文本。FileDeck 原始自有文件的许可证不能替代第三方组件许可证。

## 收尾检查

执行 simplify Standard / refactor，审查 repo_fit、quality、reuse 和 efficiency。修正核验报告可能跟随符号链接写入的问题，并增加对应边界测试。摘要函数保持局部实现，避免把打包优化器耦合到不相关的 Qt 准备模块。修正后 95 项构建工具测试通过。
