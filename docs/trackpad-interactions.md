# macOS 触控板交互

适用：SwiftUI 文件浏览、AppKit/CEF 完整宿主、Quick Look 只读预览与图片/PDF 原生编辑。最低部署版本为 macOS 14；不替换现有滚动、拖放或文档内核。

## 父子路径规则

- 水平后退每次只到当前目录的直接父目录，到活动工作区根目录停止。
- 水平前进只回到刚刚退出的直接子目录；多次退出形成逐层返回栈。
- A/B/C 同级时，从 C 后退只到它们的父目录；前进只回 C，不按文件列表顺序选择兄弟目录。
- 点击打开新分支、历史按钮导航等显式导航清空旧的手势前进链。
- 上级目录按钮/⌘↑ 与手势后退共用父子链；返回子目录按钮/⌥⌘↓ 与手势前进共用。原历史按钮/⌘[、⌘] 继续浏览历史语义。
- 返回链只在当前会话保存，子目录身份变更、删除或被替换后要求重新点击打开。选区按身份恢复，同名替换项不继承选择。

## 输入分工与反馈

| 区域 / 输入 | 处理 |
| --- | --- |
| 文件列表、导航栏纵向双指滚动 | 原生 List/ScrollView 平滑滚动，不反转系统自然方向 |
| 浏览区域水平精确滚动 | 8pt 后判断主轴，水平大于纵向 1.5 倍才截获；松手净位移至少 60pt 才导航 |
| 短移、取消、折返、惯性 | 不导航；已捕获的横向惯性不重复触发，新一轮纵向滚动立即放行 |
| 输入框、可横向滚动内容、预览/编辑、搜索、系统 sheet | 保留原始交互，不触发浏览导航 |
| 图标捏合或文件拖动中 | 暂停浏览导航，避免缩放或三指拖移时误切目录 |
| 三指/四指、右键和辅助功能配置 | 交给 macOS，不监控触摸点、不截获离散 swipe、不改系统偏好 |

导航在内容边缘显示方向、目标目录和阈值进度；提示不参与命中，结束、取消、窗口失活或进入工作层后清理。没有可用父/子目录时不截获手势。

完整宿主与独立浏览入口共用当前窗口的 AppKit 本地滚动监视器。具体浏览滚动视图保留完整事件阶段：零位移开始延迟到首个位移派发，静止更新不重置滚动轴，结束/取消仍透传；在原响应者前接入水平转发；纵向、菜单、键盘与撤销沿原链处理，卸载后恢复原响应者。相同事件去重，不依赖系统翻页动画完成回调。

## 缩放、选择和拖放

- 图标网格捏合调整 36–100pt 图标尺寸，保留原生滚动锚点；顶部视图选项提供滑杆和恢复默认大小。缩放不改变选区，键盘网格列数同步更新。
- 普通图片/PDF 只读预览继续 Quick Look，格式能力由系统提供。图片编辑使用 `NSScrollView.allowsMagnification` 保持缩放中心并平移；PDF 编辑使用 PDFKit 原生能力。
- 图片/PDF 都有缩小、放大与复原/适合窗口按钮，以及 ⌘− / ⌘+ / ⌘0；缩放不修改文件或生成文档撤销记录，外层窗口/工具栏不缩放。
- 单击选择、双击打开、多选与系统拖移继续使用原有 List、NSItemProvider 和 SwiftUI 拖放。新增目标名与复制/移动/禁止提示；禁止 proposal 拒绝实际落盘。
- 文件操作继续使用原身份验证、重名保护、批次反馈、取消与撤销。失败不提前删除源文件；提供“移动到此处”和 ⌘C 后 ⌥⌘V 的拖放替代入口；移动仅认本窗口复制时冻结的文件身份及匹配的剪贴板代次，冲突或原文件被替换时拒绝移动，支持同一撤销链。

## 验收与边界

本轮已安装构建14；293项Swift、零/非零起始各27项原生专项及37项既有交互回归通过。安装路径16项手势/按钮和2项目录快捷键检查通过；解锁后以本构建另行完成禁网Office编辑、保存、重开及关闭保护回归。锁屏期间的失败尝试单独保留，不计入通过。当前结果与构建身份写入本机 `build/trackpad-ux/report.json`。以下区分真实执行与需要额外设备的项目：

| 项目 | 方法 / 范围 |
| --- | --- |
| 父子链、多分支、根目录、替换目录、选区恢复 | Swift 模型与真实视图回归 |
| 完整原生路由、纵向/取消/惯性、多个子目录 | `FW_NATIVE_HOST_TEST_CASE=navigation-swipes bash scripts/test-native-hosts.sh`，窗口服务器事件、实际文件列表与事件标记 |
| 系统滚动轻扫开关 | 测试注入开启/关闭，不写用户系统设置 |
| 窗口尺寸 | 1440 与 860pt 原生窗口，窄窗图标视图截图 |
| 图片/PDF | 原生中心缩放、按钮/键盘入口、窗口及文件内容不变性 |
| 安装版 | 构建14正式路径手势/按钮16项、目录快捷键2项及Office回归通过，包/二进制/资源身份已核对 |
| 物理触控板 | 用户已确认事件链改动后可切换目录；最新父子链与捏合手感仍以安装后实机结果为准 |
| macOS 版本 | 当前机器 macOS 14.7.2 / ARM64；其他 macOS 版本与其他硬件尚未实测，不以部署目标或合成事件代替 |

原生事件专项必须保持自己的验收窗口在前台；若焦点被切走或正在拖动，停止投递，不能记为通过。该专项与完整 Office 编辑验收分开计数。
