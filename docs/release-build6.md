# FileDeck v0.1.2 构建 6 发布说明

发布日期：2026-10-25。适用 macOS 14+、Apple Silicon，开发预览版。
发布标签：`v0.1.2-build6`；修复源码提交：`e9e0a12393b7f2a533122e7b425c66877d2ff15d`。

## 变更与影响范围

- JPEG 未编辑普通保存及同格式另存保留原始字节；旋转后保留适用标准元数据，重复保存复用已编码结果。
- WebKit 内容进程故障后可另存已同步内存草稿或恢复编辑器，取消另存保留草稿，原文件不被覆盖。
- 目录重命名同步嵌套管理根、当前路径、历史导航、选择、展开及持久化书签。
- 新增系统草稿另存面板验收与独立工作区偏好域，回归覆盖冲突、竞态及旧回调隔离。

## 数据库、配置和接口

数据库变更、初始化 SQL、升级 SQL、回滚 SQL：无。Redis、MQ、中间件部署变更：无。
对外 API、错误码变更：无。用户配置无需迁移，应用标识仍为 `local.fileworkbench.desktop`。
仅验收环境新增 `FW_WORKBENCH_TEST_SUITE`；日常启动无需设置。

## 安装与验证

1. 从本次 Release 下载 ZIP 与 SHA256SUMS.txt，执行 `shasum -a 256 -c SHA256SUMS.txt`。
2. 正常保存并退出旧应用，解压并将完整 FileDeck.app 放入“应用程序”。
3. 打开并核对版本 0.1.2、构建 6，检查目录浏览及文档保存。

已通过：Swift 144 项、原生媒体 8 组、WebKit 恢复 12 项、原生宿主 44 项（各阶段顺序及边界见审查文档）；最终 Python 构建工具 146 项、0 跳过。
最终安装包已验证 Office 三格式离线编辑/保存/重开、系统草稿另存取消及保存、JPEG 普通保存/系统另存/旋转/重复保存，以及实际目录重命名、历史导航和正常重启恢复。
完整证据及成功标准见 [验收文档第 10 节](code-review-and-roadmap.md#10-本机安装与验收2026-10-25)。

## 风险与恢复范围

WebKit 故障采用公开委托回调注入，没有执行系统级进程 kill；只恢复存活 Swift 会话已同步的草稿，不覆盖应用主进程崩溃或机器重启后的持久恢复。
真实 JPEG 变换仍有一次有损编码，任意厂商私有元数据不在保留承诺内。中文输入法组合输入、复杂 Office 文档、首次授权和拔盘仍需专项验证。
本包使用临时签名，尚未完成 Developer ID 签名及 Apple 公证。

## 回滚与旧应用清理

本次发布后按用户要求移除本机旧 FileDeck 应用副本；本地构建 4 备份不再作为有效回滚入口。审查文档第 10 节中的旧备份路径保留为安装阶段历史依据。
需要回退时，从 [原 v0.1.2 Release（构建 5）](https://github.com/liuweqwojeo/FileDeck/releases/tag/v0.1.2) 下载旧包及其校验文件，校验后正常退出构建 6，再替换应用并核对构建号 5。回滚应用不会撤销已保存文件和目录改名，无数据库或配置回滚脚本。

源码及标签已推送。发布时核对 ZIP CRC、解压完整性、签名及 GitHub 附件大小和 SHA-256；远程发布证据见本次 Release 的校验附件与说明。
