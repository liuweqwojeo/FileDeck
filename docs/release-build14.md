# FileDeck v0.1.2 构建 14 发布说明

日期：2026-10-28。适用 macOS 14+、Apple Silicon（ARM64）；Release 配置，开发预览版。发布标签为 [`v0.1.2-build14`](https://github.com/liuweqwojeo/FileDeck/releases/tag/v0.1.2-build14)，源码与构建输入对应关系见 Release 附件 `SOURCE-CODE.md`。

## 本版变化

- 触控板水平后退只到直接父目录，每次一层；前进只回刚退出的直接子目录。同级 A/B/C 不互相滑动，点击新分支清空旧前进链，到工作区根目录停止。上级/返回子目录按钮与 ⌘↑ / ⌥⌘↓ 共用该模型，原历史按钮保持历史语义。
- 修复完整原生宿主中的滚动事件路由，包括零位移起始、结束、取消和惯性。垂直滚动保留原生方向，导航显示目标与进度，往返按文件身份恢复选区；连续上级操作受加载门禁保护。不截获三指/四指系统手势。
- 图标网格支持捏合及36–100pt大小控制。图片/PDF原生编辑界面复用NSScrollView/PDFKit缩放和平移，提供按钮和快捷键；外层窗口与工具栏不随文档放大。只读预览继续使用系统Quick Look。
- 拖放显示目标、复制/移动及禁止状态；增加“移动到此处”和 ⌘C 后 ⌥⌘V。移动仅接受本窗口复制时的冻结身份及匹配剪贴板代次，冲突或源被替换时拒绝移动，沿用原撤销链。
- 相比公开构建8，本包还包含已提交的常见编程语言新建/高亮、八项交互修复、递归搜索、非Office草稿恢复、文件操作进度/取消/撤销，以及目录和媒体性能改进。相关功能边界见[实施状态](implementation-status.md)、[八项交互修复](interaction-fixes.md)和[触控板规范](trackpad-interactions.md)。

## 下载、校验与升级

ZIP：`FileDeck-0.1.2-build14-macOS-arm64.zip`，792,398,782 字节，约792.40 MB（755.69 MiB）。

SHA-256：`d358fc43be562589ac126dda68b589bfc1fef8090f6afbb3d4bd96dc3453d48c`。

1. 从本次Release下载ZIP与`SHA256SUMS.txt`，放在同一目录执行 `shasum -a 256 -c SHA256SUMS.txt`。
2. 保存文档并正常退出旧版，解压后将完整`FileDeck.app`替换到“应用程序”。不要合并新旧应用包内容。
3. 启动核对版本0.1.2、构建14。进入子目录检查逐层返回，并复核常用文档的编辑和保存。

Release另附`INSTALL.md`和`SOURCE-CODE.md`。无需另装Node、Python或Microsoft Office；Accessibility仅用于开发者主动运行的验收工具，应用日常使用无需此权限。

## 兼容性与边界

本机验证环境为macOS14.7.2 / ARM64。其他macOS版本、其他硬件及最终版本的物理捏合手感未实测；系统开关采用测试注入，未修改用户触控板设置。Office中文通过SDK测试入口输入，系统输入法组合、复杂文档兼容性及真实拔盘/断电不由本轮替代。

仍使用临时签名，尚未完成Developer ID签名及Apple公证。数据结构、SQL、服务端配置、中间件和对外API无迁移要求；bundle ID保持`local.fileworkbench.desktop`。图标大小保存在本机偏好中，手势返回链只在当前会话保留。
