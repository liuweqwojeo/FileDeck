# FileDeck 交互优化与验收

本文保留前一轮布局优化的验收记录。后续八项修复、当前行为与新增验证见 [八项交互修复](interaction-fixes.md)。

本轮保留 SwiftUI + AppKit、现有 Office/WKWebView/CodeMirror 编辑内核和文件安全实现，重组了常用操作入口。整体交互约定见 [DESIGN.md](../DESIGN.md)。

## 任务路径变化

| 任务 | 原问题 | 已实现 | 预期收益与安全边界 |
| --- | --- | --- | --- |
| 添加目录 → 浏览 → 预览 | 工具栏重复，预览依赖用户发现双击/空格 | 顶部保留导航/筛选/搜索/视图；添加目录在侧栏与工作区菜单；选中后显示预览 | 添加仍通过系统授权；单击只选择，空格/显式预览沿用同一工作层，关闭恢复焦点/滚动/选择 |
| 找到 → 编辑 → 保存 → 返回 | 文本先打开预览再切编辑，返回为无文字关闭图标 | 单选显示编辑，⌘E 直接进入安全文本宿主并聚焦正文；“返回浏览”“保存并返回”有标签；⌘↩ 合并保存与返回 | 省去预览到编辑的额外切换；失败、冲突、另存取消或保存中继续输入均保留原会话。CSV/PDF/图片/Office 继续原生编辑路由 |
| 搜索 → 查看 → 定位 | 筛选和递归搜索含义不清，固定弹窗切断上下文 | “筛选当前目录”与“子目录与内容”明确分工；递归搜索嵌入主内容区；结果可预览或定位 | 搜索不改当前浏览状态；预览关闭继续同一结果；定位验证身份后进入父目录。范围、排除、上限和取消语义不变 |
| 多选 → 操作 → 进度 → 撤销 | 批量入口靠右键，长结果持续占顶部 | 选区条显示数量、复制、操作菜单，复用右键捕获的批次；完成摘要支持展开逐项详情；撤销持续可见 | 取消仍等待当前系统调用结束；已提交项目保留；撤销仍有身份/重名保护，限本窗口最近批次 |
| 继续工作区 → 草稿 | 恢复入口主要在欢迎页和原生菜单 | 保留欢迎页继续；工作区菜单和侧栏增加恢复草稿、继续编辑入口，未保存有文字/圆点 | 不重建原编辑内核；恢复仍为独立未命名副本，首次保存另存，不覆盖原路径 |

## 外观、焦点与窗口

采用 awesome-design-md 中 Linear 的文字层级、细分隔线和克制强调色，以及 Raycast 的紧凑工具行、有标签动作与快捷键提示。参考来自本地固定设计快照，不宣称是品牌当前网站或其原生应用的完整规范。

工作区跟随系统浅深色和用户强调色；去掉强制 Aqua/浅色，动态 AppKit 色彩覆盖 SwiftUI、工作层和编辑条。CodeMirror 深色控件、行号、当前行和光标增加对应样式。Office/PDF/图片的文档纸张色仍由原内核管理。

窗口最小 860×660；⌥⌘S 折叠侧栏且焦点转给可见筛选框。⌘F 聚焦当前目录筛选，⇧⌘F 打开递归搜索，⌘E 编辑，⌘S 保存，⇧⌘S 另存，⌘↩ 保存并返回，Esc/⌘W 经过关闭保护返回。只读预览在中性容器焦点下可空格关闭，正文有焦点时继续保留文本键盘语义。

隐藏内容面同时禁用指针、快捷键和可访问性。关闭搜索取消未完成扫描及在途定位，防止重开后执行迟到的旧定位。直接进入编辑会聚焦正文，避免再次点击。批量菜单复用捕获的选择与身份，菜单打开后的选择变化不能扩大操作对象。

## 验证边界

- 系统目录授权面板实测打开/取消；目录添加确认后的业务与工作区恢复走真实 BrowserStore 路径，本轮没有自动点击授权确认按钮。
- 完整 Debug 构建与隔离原生宿主不等于已安装应用验收；本轮没有安装、发布或生成分发包。
- Office 混合标签、真实慢卷/拔盘/断电、跨卷硬件行为不由本轮 UI 验收替代；相关原有测试与保护保持各自范围。
- 搜索只提取支持的文本内容，不新增 PDF/Office 全文解析或全盘索引。
- “保存并返回”适用于当前原生文本工作层；其他编辑内核沿用保存和返回入口。
